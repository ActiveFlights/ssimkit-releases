# SSIM Toolkit — Releases

Download the latest build of **SSIM Toolkit** from the
[Releases page](https://github.com/ActiveFlights/ssimkit-releases/releases).

This repository distributes installers only — it contains no source code.

## Downloads

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `.dmg` |
| Windows | `.exe` (installer) |
| Linux | `.AppImage` |

> **macOS:** builds are for Apple Silicon. Intel Macs are not supported.

## Updates

The app checks for updates itself — open **About** and use *Check now*. Update
checks send no schedule data; every update is cryptographically signed and
verified before it is installed.

## Support

Use the in-app **Send feedback** form to report a problem.
